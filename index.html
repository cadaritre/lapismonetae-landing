Quick Start

# Clone the repository
$ git clone https://github.com/nicokeyboard/lapis-monetae.git
$ cd lapis-monetae

# Run a mainnet node
$ cargo run --release --bin lmtd -- --utxoindex

# Start mining (in another terminal)
$ cd tools/xmrig-lmt/gui
$ python app.py
